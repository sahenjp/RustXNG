# RustXNG と Exa の比較（2026-10-31 時点）

## 1行で言うと

**RustXNG は無料・自己ホストで、検索の当たり具合は Exa と同等かわずかに上。ただし Google が使えない制約がある。**

## 何を測ったか

- **100 問**の検索課題（「python dict get method」「rust プログラミング言語 公式」など）
- 各問いに**正解のページ**を用意し、上位 10 件にそれが入ったか・何位だったかを測定
- 同じ問題を Exa（有料API）と RustXNG（無料・APIキーなし）に投げて比較

## 結果

| 指標 | RustXNG | Exa | 意味 |
| --- | ---: | ---: | --- |
| **1位で当てた数** | **79 / 100** | 77 / 100 | 一番上に出せたか（体感で最も大事） |
| **5位以内で当てた数** | **92 / 100** | 91 / 100 | 上位5件に答えがあるか |
| **平均順位スコア（MRR）** | **0.853** | 0.840 | 1位=1.0、2位=0.5…の平均。高いほど上に出せている |

## それ以外の比較

| 観点 | RustXNG | Exa | どちらが有利 |
| --- | --- | --- | --- |
| 料金 | **0 円** | 従量課金 | **RustXNG** |
| 自分のサーバーで動かせる | **できる** | できない | **RustXNG** |
| API キー | **不要** | 必要 | **RustXNG** |
| 取得できる本文の量 | **約32,000字** | 約9,000字 | **RustXNG** |
| 速度（初回） | 0.8〜1.6 秒 | **0.6 秒** | Exa |
| 速度（同じ検索の2回目） | **0.01 秒** | 0.6 秒 | **RustXNG** |
| 上流サイトにブロックされたとき | 弱い（自分で回避策が必要） | 影響なし | Exa |

## わかりやすい例え

- **Exa** は「自前の巨大な本棚を持っている図書館」。速くて安定しているが、利用料がかかる
- **RustXNG** は「行ける図書館を全部回って、良い本を1つのリストにまとめる司書」。無料で蔵書も多いが、閉まっている図書館（Google）には入れない

## 正直な注意点

1. **測定には振れがあります** — 同じ設定でも hit@1 は 77〜84 の幅で動きます（上流サイトの混雑具合で変わる）。上の数字はその中の代表値です
2. **Google は使えません** — この環境では WML 版が 403、通常版は JS 必須、ヘッドレスブラウザはボット判定で拒否されました。Google を除いた数字です
3. **Tavily には大差で勝っています** — 参考までに併記しました

## 再現方法

```bash
rustxng &
python3 tools/eval_quality.py --base http://127.0.0.1:8888 --delay 1.0
```

設問と正解は `bench/quality-questions.json`、生データは `bench/eval-100-*.json` にあります。
