# RustXNGとExaの過去の比較（2026-10-31）

このページは、特定の100問の参照URL検索について公表した過去の測定記録です。
RustXNGは外部検索プロバイダーの結果を統合するメタ検索エンジンであり、検索インデックス全体を自前で提供するものではありません。
この比較だけで、一般的な検索品質、回答の正確さ、可用性、費用、利用許諾の優劣は判断できません。

## 比較するときに分ける条件

- RustXNG本体に検索ごとのソフトウェア利用料はありません。サーバー、回線、保守、認証付きプロバイダーの費用は別に発生します。
- APIキーが不要かどうかは選択したプロバイダーによります。アクセスできることは、自動取得や再利用の許可を意味しません。
- 過去の約32,000字対約9,000字という本文量は取得量の測定です。関連性や正確さ、モデルに必要なトークンの少なさを示しません。
- RustXNGのキャッシュヒット時の約0.01秒と、別条件の商用APIの約0.6秒を、同条件の初回検索として比較しません。
- 外部検索元のブロック、CAPTCHA、429、形式変更はRustXNGの結果に影響します。商用APIについても、個別の測定なしに「影響なし」とは言えません。
- Googleを取得できなかったという旧環境の記録と、現在mainからGoogle系実装を削除した状態は区別します。

プロバイダー構成と利用条件の見直し後の性能は未測定です。過去の値を、新しい既定構成の到達率として掲載しません。
SealQAの参照ページ到達率は別の設問・指標による測定です。[条件と制約](SEALQA.md)を参照してください。
