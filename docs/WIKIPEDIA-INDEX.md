# Wikipedia の自前インデックス（公式ダンプから）

`rustxng-wikidump` は、Wikipedia の公式ダンプから**記事の冒頭**を取り出して、ローカルの検索インデックスを作ります。
Wikimedia がダンプを配布しているのは、こうした再利用のためです。検索 API を何度も叩く必要がなく、外部への負荷もありません。

## 作り方

```bash
# 公式ミラーの日付ディレクトリを指定する（最新の日付は各ミラーの一覧で確認）
rustxng-wikidump --index index-wikipedia \
  --base-url https://ftp.acc.umu.se/mirror/wikimedia.org/dumps/enwiki/20261001/ \
  --parallel 3
```

- `curl` と `bzip2` が必要です。
- ダンプは**ストリームのまま処理**します。ダウンロードしたファイルは残らず、ディスクに書くのはインデックスだけです（英語版で約 3 GB）。
- パートごとに記事をまとめてから書き込むので、途中で失敗しても中途半端な記事は残りません。完了したパートは `<index>/parts-done.txt` に記録され、同じコマンドを再実行すると続きから進みます。
- 同時接続は最大 4（既定 3）。ミラーへの負荷を抑えるためです。
- 取り込むのは、通常の記事（名前空間 0）のうちリダイレクト・曖昧さ回避・極端に短い項目（既定 1,500 バイト未満）を除いたものです。各記事からはタイトルと、テンプレート・表・脚注などを除いた冒頭 800 字を取ります。

## 使い方

```toml
[search]
wikipedia_index_path = "index-wikipedia"
local_index_merge = true      # false にすると索引は保持したまま順位から外す
```

質問文は話題語に絞られ、**1 語でも一致すれば候補**になります（順位は BM25 が決めます）。
自前クロールのインデックス（`local_index_path`）と違い、緩い一致にしているのは、百科事典では質問の語が記事の冒頭に散らばるのが普通だからです。

## 実測

2026-11-03 の英語版ダンプ（20261001）から 71 パートを取り込みました。

| 項目 | 値 |
| --- | ---: |
| 取り込んだ記事 | 6,185,457 |
| インデックスの大きさ | 3.0 GB |
| 所要時間 | 約 28 分（ミラーから 3 並列） |
| 途中の失敗 | 数パートで接続が切れたが、自動の再試行で全パート成功 |

クリーン構成の SealQA（254 問）では、このインデックスを加えて hit@10 が 102 → 119、MRR が 0.253 → 0.311、結果ゼロの質問が 13 → 0 になりました（`docs/CLEAN-PROFILE.md`）。

## ライセンス

Wikipedia の本文は CC BY-SA 4.0 です。インデックスは派生物なので、再配布する場合は帰属表示と同じ条件での提供が必要です。ローカルで使うだけなら問題ありません。結果の URL は Wikipedia の記事を指します。

## 制約

- 英語版のみを想定しています（`--wiki` で他言語の接頭辞を指定できますが、トークナイザは英語向けです）。
- wikitext は描画せず、冒頭の散文だけを粗く取り出します。数式・表・テンプレートが生成する文は含まれません。
- 記事の人気（閲覧数やリンク数）は使っていません。短い無名の記事が有名な記事より上に来ることがあります。
- 更新は差分ではなく、ダンプごとに作り直しです。
